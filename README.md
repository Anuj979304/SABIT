\# SABIT



Skill hai? Sabit karo.



SABIT is an AI-powered student skill verification and career readiness platform.



\## Features



\- Resume skill analysis

\- Skill gap detection

\- Personalized proof projects

\- GitHub project verification

\- Skill Passport

\- Career readiness tracking



\## Technology



\- Python

\- FastAPI

\- JavaScript

\- HTML

\- CSS

\- GitHub API
